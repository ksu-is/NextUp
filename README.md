# NextUp

### A Video Game Backlog Tracker Built with Python

## About the Project

NextUp is a Python program I'm making to help people organize their video game collections and figure out what to play next.

With games spread across different platforms like Steam, Epic Games, Xbox, and PlayStation, it can be a major pain to remember which games you own, have started, or have finished. The main goal of NextUp is to make managing a growing game backlog easier by keeping everything organized in one place.

## Planned Features

Here are some of the features I would like to include:

**Game Library:** Add games to a personal collection and organize them by title, genre, and platform.

**Completion Status:** Mark games as Not Started, Playing, Completed, or Dropped.

**Priority System:** Give games a priority level based on how much you want to play them.

**What Should I Play Next? Wheel:** A spinning wheel that randomly selects a game based on preferences such as genre or priority. (Def My Favorite Idea)

**Save Progress:** Save game information so it isn't lost when the program closes.

## How do I Plan to Build It?

I mostly plan on using Python as the main programming language for NextUp. I'll start by developing a basic program that allows users to add, remove, and update games in their collection.

Once the basic features are working, I would like to experiment with adding a graphical interface and the spinning wheel feature.
